# מחולל תחקיר

פותחים את `index.html` בדפדפן (צריך אינטרנט בשביל הפונט וספריית ה-Word).

## מבנה התיקייה

| מה | איפה | מה יש שם |
|---|---|---|
| הדף עצמו | `index.html` | הטופס, התצוגה המקדימה ומבנה המסמך (טקסט בלבד, בלי קוד) |
| עיצוב | `css/style.css` | צבעים, גדלים, פונטים, ועיצוב דף ה-A4 |
| תמונות | `assets/images/` | לוגו בה"ד (`behad.png`) ולוגו של כל גדוד |
| הגדרות | `js/config.js` | רשימת המגמות והגדודים, ואיזה קובץ לוגו שייך לכל גדוד |
| תאריכים | `js/dates.js` | המרה לתאריך עברי ולועזי שמופיעים במסמך |
| הטופס | `js/form.js` | בחירת גדוד, מילוי המסמך, תצוגה מקדימה, חזרה לעריכה |
| Word | `js/word-export.js` | בניית קובץ ה-Word והורדה שלו |
| לוגואים ל-Word | `js/logos-data.js` | אותן תמונות בפורמט טקסט. נוצר אוטומטית, לא לערוך |
| כלי עזר | `tools/build_logos.py` | בונה מחדש את `logos-data.js` מהתמונות |

## שינויים נפוצים

- **להוסיף גדוד:** מוסיפים אותו ב-`MEGAMOT` וב-`LOGO_FILES` (`js/config.js`), שמים את התמונה ב-`assets/images/`, ומריצים `python3 tools/build_logos.py`.
- **להחליף לוגו:** מחליפים את קובץ ה-PNG (אותו שם) ומריצים `python3 tools/build_logos.py`. בלי זה התמונה תתעדכן בדף אבל לא בקובץ ה-Word.
- **לוגו נראה קטן, או עם רקע שחור/לבן במקום שקוף:** מריצים `python3 tools/build_logos.py --trim` (דורש `pip install pillow numpy`). הכלי גוזם שוליים ריקים, הופך רקע שחור/לבן חיצוני לשקוף, ושומר עותק של המקור ב-`assets/images/_originals`.
- **לשנות עיצוב:** `css/style.css`.
- **לשנות את מבנה קובץ ה-Word:** `js/word-export.js`, בפונקציה `buildDocx`.
